# NTN Greedy Transmitter Selection

Reproducibility code for the manuscript:

**On Positioning in Non-Terrestrial Networks: Greedy Algorithms for Optimizing Transmitter Allocation**

This repository contains the MATLAB implementation used to reproduce the nominal NTN transmitter-selection baseline and the three experiments used in the current manuscript:

1. short-term temporal evolution;
2. selection relevance and robustness to impulsive pseudorange errors;
3. HAPS availability and LEO compensation.

The public workflow uses portable MATLAB code, archived TLEs, the included Vallado SGP4 implementation, and a portable ITU-R P.2145/P.676 atmospheric model.

---

## Nominal candidate pool

The nominal candidate pool contains 26 transmitters:

- 4 synthetic HAPS;
- 8 Starlink LEO satellites;
- 7 O3b/O3b mPOWER MEO satellites;
- 7 GEO satellites.

The receiver is fixed in Rio de Janeiro, Brazil:

- latitude: `-22.8596582 deg`;
- longitude: `-43.2303236 deg`;
- height: `10 m`.

Reference epoch:

```text
01-Aug-2026 12:00:00 UTC
```

Elevation masks:

- HAPS: `15 deg`;
- LEO/MEO/GEO: `5 deg`.

The nominal transmitter-selection target is

```text
alpha_CRB <= 0.6 m
```

where `alpha_CRB` denotes the scalar positional Cramér-Rao bound used by the selection algorithms.

## Reproducibility design

Orbital propagation is performed from the archived TLEs using the included Vallado SGP4 implementation with WGS-72 constants.

The main orbital and positioning chain is

```text
archived TLEs
    -> Vallado SGP4 / WGS-72
    -> TEME-to-ECEF conversion
    -> orbital catalog
    -> nominal candidate pool
    -> portable link budget
    -> FA / BE transmitter selection
    -> Experiments 1, 2, and 3
    -> paper figures
```

The fixed Earth-orientation parameters used by the paper experiment are defined in

```text
matlab/propagation/paper_epoch_eop.m
```

The Vallado wrapper is

```text
matlab/propagation/propagate_tle_vallado.m
```

and the included Vallado routines are stored in

```text
third_party/vallado_sgp4/
```

The canonical repository-path configuration is

```text
matlab/setup/setup_paths.m
```

`setup_paths.m` adds the MATLAB source tree and the included Vallado SGP4 directory to the MATLAB path.

## Atmospheric model

The current link-budget pipeline uses:

- ITU-R P.2145 annual-median meteorology;
- ITU-R P.676-13 Annex 2 gaseous attenuation;
- architecture-specific RF assumptions for HAPS, LEO, MEO, and GEO.

The P.2145 quantities used by the model are:

- atmospheric pressure `P`;
- temperature `T`;
- water-vapor density `rho`;
- integrated water-vapor content `V`.

The implementation is under

```text
matlab/atmosphere/
```

The nominal link budget is generated by

```text
matlab/setup/build_nominal_link_budget.m
```

### Required local P.2145 data

The full gridded P.2145 annual data set is large and is **not versioned in Git**.

Before running the link-budget builder on a fresh clone, populate

```text
data/itu/p2145/annual/
```

with the following directories:

```text
P_Annual/
T_Annual/
RHO_Annual/
V_Annual/
```

The expected layout is therefore

```text
data/
`-- itu/
    `-- p2145/
        `-- annual/
            |-- Attribution&disclaimer.txt
            |-- P_Annual/
            |-- T_Annual/
            |-- RHO_Annual/
            `-- V_Annual/
```

The repository tracks the attribution/disclaimer file, but the large map directories remain local.

A quick MATLAB check is

```matlab
p2145Path = fullfile(repoRoot,'data','itu','p2145','annual');

isfolder(fullfile(p2145Path,'P_Annual'))
isfolder(fullfile(p2145Path,'T_Annual'))
isfolder(fullfile(p2145Path,'RHO_Annual'))
isfolder(fullfile(p2145Path,'V_Annual'))
```

All four calls should return logical `1`.

### MATLAB Online note

The same repository can be used in MATLAB Online. A typical location is

```text
/MATLAB Drive/ntn-greedy-transmitter-selection
```

For large P.2145 archives that exceed the direct MATLAB Online upload limit, transfer them through MATLAB Drive or MATLAB Drive Connector and extract them so that the four directories above are directly under `data/itu/p2145/annual/`.

Avoid an accidental nested layout such as

```text
data/itu/p2145/annual/annual/P_Annual/
```

because the scripts expect

```text
data/itu/p2145/annual/P_Annual/
```

`restoredefaultpath` is not required for MATLAB Online.

## Main reproduction workflow

After configuring the MATLAB path, execute the pipeline in this order.

### 1. Build the orbital catalog

```matlab
build_orbital_catalog
```

Outputs:

```text
results/orbital_catalog.mat
results/orbital_catalog.csv
```

### 2. Build the nominal 26-transmitter pool

```matlab
build_nominal_candidate_pool
```

Outputs:

```text
results/candidate_pool_26.mat
results/candidate_pool_26.csv
```

### 3. Build the nominal link budget

Make sure the P.2145 data directories are present, then run

```matlab
build_nominal_link_budget
```

Outputs include

```text
results/link_budget.mat
results/link_budget.csv
```

### 4. Run the nominal transmitter-selection algorithms

```matlab
run_FA
run_BE
```

FA denotes **Forward Adding** and BE denotes **Backward Elimination**.

### 5. Run Experiment 1

```matlab
run_experiment1_temporal
make_experiment1_figures
```

### 6. Run Experiment 2

```matlab
run_experiment2_selection_robustness
make_experiment2_figures
```

Experiment 2 uses `10,000` Monte Carlo trials for each outlier-count case, so this step is substantially slower than the other experiments.

### 7. Run Experiment 3

```matlab
run_experiment3_availability
make_experiment3_figures
```

## Expected nominal baseline

For the nominal 26-transmitter pool and the `0.6 m` target, the current validated baseline is:

| Method | K | `alpha_CRB` [m] | PDOP | Subset evaluations |
|---|---:|---:|---:|---:|
| Full pool | 26 | 0.494740028194 | 1.073010328860 | - |
| FA | 11 | 0.599850648950 | 1.471031734645 | 15083 |
| BE | 11 | 0.599850648950 | 1.471031734645 | 296 |

FA and BE return the same nominal subset:

```text
1 2 3 5 8 9 10 11 17 18 19
```

with composition

```text
3 HAPS + 5 LEO + 3 MEO + 0 GEO
```

This is the reference baseline for the current repository. Older `K=12` outputs belong to previous model versions and should not be used as the regression target.

## Experiment 1 - short-term temporal evolution

Experiment 1 evaluates the same nominal transmitter identities at

```text
t = {0, 60, 120, 180} s
```

At each epoch the script:

1. propagates the orbital transmitters;
2. keeps the synthetic HAPS fixed;
3. recomputes geometry and visibility;
4. recomputes atmospheric loss and the link budget;
5. runs FA and BE.

The expected selected-set sizes are

```text
t [s] :   0   60   120   180
K     :  11   12    12    15
```

Representative validated bounds are:

| Time [s] | No selection [m] | FA [m] | BE [m] |
|---:|---:|---:|---:|
| 0   | 0.494740028194 | 0.599850648950 | 0.599850648950 |
| 60  | 0.515973078613 | 0.587393612791 | 0.587393612791 |
| 120 | 0.514853404897 | 0.596277143891 | 0.592199647978 |
| 180 | 0.571984116755 | 0.594751446289 | 0.594751446289 |

Numerical outputs are written to

```text
results/experiment1_temporal/
```

The plotting script generates the temporal bound figure, four skyplots, and a standalone skyplot legend under

```text
results/experiment1_temporal/figures/
```

## Experiment 2 - selection relevance and outlier robustness

Experiment 2 combines two analyses.

### Part A - selection relevance

The current nominal subset size is

```text
K = 11
```

The script compares:

- the FA-selected subset;
- the BE-selected subset;
- the `K` transmitters with the highest `C/N0`;
- the `K` transmitters with the highest elevation;
- `50,000` uniformly sampled random full-rank subsets of the same size.

The random experiment uses

```text
N_random = 50000
rng(2,'twister')
```

Representative validated results are:

| Method | K | Positional bound [m] | Target reached |
|---|---:|---:|:---:|
| FA selected | 11 | 0.599850648950 | Yes |
| BE selected | 11 | 0.599850648950 | Yes |
| Highest-`C/N0` subset | 11 | 0.736326998893 | No |
| Highest-elevation subset | 11 | 1.589955034306 | No |

For the `50,000` random subsets:

```text
Full-rank probability            : 100 %
P(random alpha_CRB <= 0.6 m)    : 0 %
Random median alpha_CRB          : 0.898331921978 m
Random 5th / 95th percentile    : 0.695793795962 / 1.359223273956 m
Best sampled random alpha_CRB    : 0.606451466984 m
```

### Part B - impulsive pseudorange errors

The robustness experiment uses

```text
Monte Carlo trials per case : 10000
N_out                       : 0, 2, 4, 6
Outlier magnitude           : 20 to 100 sigma_rho
Random generator            : rng(2,'twister')
```

The experiment compares:

- full-pool WLS without rejection;
- residual-aided rejection followed by FA;
- residual-aided rejection followed by BE;
- exact-detection-and-feasible conditioned RMSE.

Representative global RMSE values are:

| `N_out` | No selection [m] | FA [m] | BE [m] |
|---:|---:|---:|---:|
| 0 | 0.497544 | 0.600842 | 0.600842 |
| 2 | 8.887405 | 0.596020 | 0.596979 |
| 4 | 12.724343 | 1.044925 | 1.043584 |
| 6 | 15.344302 | 2.555098 | 2.555546 |

For `N_out = 4` and `6`, the global FA/BE RMSE includes trials in which outlier detection or target feasibility fails. When conditioning on exact detection and feasible selection, the FA/BE RMSE remains close to the `0.6 m` positioning target.

Experiment 2 outputs are written to

```text
results/experiment2_selection_robustness/
```

The main paper figures are

```text
results/experiment2_selection_robustness/figures/
    experiment2_selection_necessity.pdf
    experiment2_robustness_rmse.pdf
```

PNG and MATLAB FIG versions are also generated.

## Experiment 3 - HAPS availability and LEO compensation

Experiment 3 contains two parts.

### Part A - HAPS availability

The nominal 26-transmitter pool is evaluated under maximum selected-HAPS limits

```text
4, 2, 0
```

Both FA and BE are recomputed under each HAPS constraint.

### Part B - LEO compensation without HAPS

With no HAPS, the number of available LEO candidates is increased through the nested cases

```text
8, 12, 16, 20 LEO
```

while keeping

```text
7 MEO + 7 GEO
```

The additional LEO candidates are taken from the archived orbital catalog at the same reference epoch.

The script performs internal consistency checks to verify that the overlapping 8-LEO + 7-MEO + 7-GEO links reproduce the nominal link-budget values.

Numerical outputs are written to

```text
results/experiment3_availability/
```

The Experiment 3 plotting script exports

```text
results/paper_figures_experiment3/
    haps_availability.pdf
    experiment3_leo_compensation.pdf
```

PNG and MATLAB FIG versions are also generated.

## Validation

The main reproduction pipeline is independent of STK.

The repository nevertheless retains validation utilities under

```text
matlab/validation/
```

and

```text
tests/
```

Examples include checks for:

- nominal visibility;
- nominal orbital-pool consistency;
- HAPS geometry;
- P.2145 meteorology at the Rio de Janeiro receiver location;
- Vallado propagation for individual TLEs;
- nominal positioning and transmitter selection;
- gas-attenuation model comparisons;
- exact-subset validation.

`matlab/validation/read_stk_ephemeris_at_epoch.m` and STK-based checks are validation-only utilities and are not required for the public reproduction workflow.

## Generated files and version control

Large regenerable outputs are intentionally excluded from Git, including:

- experiment-specific `.mat` files;
- Monte Carlo trial tables;
- generated PNG/PDF/FIG files;
- local P.2145 map directories;
- local archival material.

The source code, TLE archive, small reference files, and scripts required to regenerate the reported results remain versioned.

Do not treat generated experiment outputs as hidden inputs: they can be rebuilt from the scripts and local P.2145 data using the workflow above.
